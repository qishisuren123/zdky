Open source · idea-generation pipeline

AutoResearch V3

Turns multi-source research signals — papers, forums, blogs, AI media, trending repos — into candidate research ideas, then cross-validates the strongest ones across multiple LLMs.

What's actually in this repository

This is the idea-generation pipeline only: signal collection, filtering, and multi-model idea forging. It does not include a downstream execution runtime that turns an idea into code/experiments — that hasn't been open-sourced.

Signal collectors

arXiv, HuggingFace Daily Papers, OpenReview, RSS feeds, Hacker News, GitHub Trending — mostly official APIs.

Idea Forge

Multi-model idea generation, 3-reviewer cross-validation (≥2/3 to pass), freshness refresh, plan drafting.

Multi-provider LLM client

Anthropic Messages API, OpenAI Chat Completions, Gemini API key or Vertex — configured entirely via environment variables.

Run it with one API

If you only have a single OpenAI-compatible endpoint, three environment variables are enough to run the full pipeline end to end.

export AUTORESEARCH_API_BASE_URL=https://your-provider.example.com/v1
export AUTORESEARCH_API_KEY=your_api_key_here
export AUTORESEARCH_API_MODEL=your-model-name   # optional

pip install -r requirements.txt
python daily_full.py
Trade-off: the idea-review step is designed as a 3-independent-model cross-validation panel to reduce single-model bias. In this single-endpoint mode, all three reviewer roles route to the same model — you get 3 review passes from one model, not genuine cross-model review. See open_source_scope_notes.md for the full list of behavior differences in this mode.

Scope notes — what's excluded, and why

  • No downstream execution runtime (code/experiments/results) — this release stops at idea + plan generation.
  • knowledge_base/ domain-knowledge files are not included; code degrades gracefully (empty context) without them — bring your own.
  • No bundled research-report generator or coding-agent runtime — those are separate systems, excluded pending licensing/provenance review.
  • Two collectors touch sites with anti-scraping measures or unofficial APIs (Chinese AI media via Jina Reader, X/Twitter via Scweet/twikit). Both are clearly flagged in their docstrings and the Twitter path is disabled by default.
